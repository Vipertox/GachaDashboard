# Verhaltenskodex

Dieses Projekt folgt dem [Contributor Covenant, Version 2.1](https://www.contributor-covenant.org/de/version/2/1/code_of_conduct/).

Kurz: Wir gehen respektvoll miteinander um, unabhängig von Herkunft, Identität oder Erfahrung. Belästigung, Beleidigungen und persönliche Angriffe werden nicht toleriert.

Verstöße können vertraulich über [„Report a vulnerability“](https://github.com/Vipertox/GachaDashboard/security/advisories/new) oder per Direktnachricht an [@Vipertox](https://github.com/Vipertox) gemeldet werden. Maintainer dürfen Beiträge entfernen und Personen vom Projekt ausschließen, die gegen diesen Kodex verstoßen.
