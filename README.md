# GachaDashboard

Cross-Platform Gacha Dashboard: zeigt auf einen Blick, wie voll die regenerierenden Ressourcen in Genshin Impact, Honkai: Star Rail und Zenless Zone Zero sind und wann sie überlaufen. Wuthering Waves ist vorerst als Platzhalter vorgesehen.

Eine Codebasis für Android, Windows und den lokalen Browser.

## Stack

React + TypeScript, Vite, Tailwind CSS, TanStack Query, Tauri 2

## Status

Konzeptphase. Das vollständige Konzept mit Datenquellen, Architektur, Datenmodell, UI und Umsetzungsplan liegt unter [docs/Konzept.md](docs/Konzept.md).

## Hinweis

Rein private App ohne eigenen Server und ohne Store-Veröffentlichung. Gespeichert werden nur HoYoLAB-Tokens (im sicheren Speicher des Betriebssystems) und Profil-Einstellungen, keine Spieldaten.
